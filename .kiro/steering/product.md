# Sand Dollar - Personal Finance Management

Sand Dollar is a comprehensive personal finance management application that helps users track spending, set budgets, manage financial goals, and gain insights through AI-powered financial assistance.

## Core Features

- **Bank Integration**: Secure account linking via Plaid API with real-time balance and transaction sync
- **Spending Analytics**: Daily and category-based spending analysis with trend comparisons
- **AI-Powered Budgeting**: OpenAI-driven budget planning and financial assistant
- **Goal Management**: Financial goal setting and progress tracking
- **Security-First**: JWT authentication, AES-GCM encryption, CSRF protection

## Target Users

Individual users seeking to better understand and manage their personal finances through automated tracking, intelligent budgeting, and goal-oriented financial planning.

## Development Philosophy

- **Security-First**: All sensitive data encrypted, secure token management
- **Production-Ready**: Proper error handling, logging, containerization
- **Modern Stack**: Latest frameworks and best practices
- **Educational Purpose**: Financial advice is educational only, not professional guidance
